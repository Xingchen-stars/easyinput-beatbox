# EasyInput Beatbox 1.0.0 发布清单

这份清单区分“软件已构建”“真实开发板已验收”和“固定版本已备份”。2026-10-01 用户要求优先保存当前可用版本，因此 `v1.0.0` 作为可恢复备份发布；下面未完成的项目保持未完成，不能因创建标签就改写为全部通过。

## 已完成的软件检查

- [x] 删除网页 Wi-Fi 配网、网络密码和设备配网码界面
- [x] BLE GATT 与 USB Serial 共用协议 v3
- [x] 停止时 S7 长按三秒才开放新电脑授权窗口
- [x] 网页 TypeScript 类型检查通过
- [x] 网页 27 个自动化测试通过
- [x] 网页 Vite 生产构建通过
- [x] ESP-IDF 5.5.5 固件构建通过
- [x] Beatbox 应用镜像小于 `0x200000` 分区上限
- [x] 发布包固定使用 `0x430000`，不使用单工程默认 `0x10000`
- [x] GitHub Pages 工作流已准备

## 必须在真实开发板上完成

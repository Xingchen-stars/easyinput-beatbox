# Beatbox v1.0.0：浏览器钥匙版

保存日期：2026-10-01。硬件：EasyInput V2.0 / ESP32-S3，16 MB Flash、8 MB PSRAM。板端项目版本为 1.0.0，ESP-IDF 构建版本为 5.5.5。

这是用户确认“蓝牙可以连接、USB 备用恢复可用”后要求永久保存的一版。它是可恢复的固定版本，仍带白盒诊断能力；GitHub Release 按预发布备份标记，未完成的回归项目继续保留。

## 这一版做了什么

板端独立运行节拍器和六轨 16 步鼓机，包含 A/B/Fill、Swing、Live Pad、三档有声速度选择，以及与 EasyInput 键盘固件之间的顶层模式选择。网页负责显示、编辑 Pattern、导入导出和 REC 叠录，日常用蓝牙直连，USB 作为备用。

取消了网页 Wi-Fi 配网、网络密码和设备配网码。首次连接时，停止播放并按住实体 S7 三秒，蓝灯亮起后打开 60 秒登记窗口。网页选择 `EasyInput Beatbox` 后自动生成并保存一份随机钥匙；以后同一浏览器用钥匙回答开发板的新挑战。只有授权通过以后，普通鼓机命令才开放。

“同一浏览器”还要求是同一个网站地址。`localhost`、`127.0.0.1`、不同端口和 GitHub Pages 是不同网站身份。换网站、换浏览器或清除网站存储后，要重新按 S7 登记。最多保留三份浏览器凭据。这个流程不要求输入配网码，也不会切断电脑原来的 Wi-Fi。

## 怎样保存和找回

程序版本：`v1.0.0`；完整恢复资料标签：`v1.0.0-backup.1`。原标签和第一次上传的附件保留不覆盖，恢复时优先使用带 `backup1` 的源码备份，见 [修正说明](v1.0.0-backup1.md)。固定更新目录：[release-v1.0.0-browser-hmac](../../artifacts/release-v1.0.0-browser-hmac/README.md)。

GitHub Release 资产：

- `easyinput-beatbox-firmware-v1.0.0-browser-hmac.zip`：本版已烧录的应用镜像、分区文字表、实际构建配置、依赖锁、源文件指纹和烧录说明。
- `easyinput-beatbox-web-v1.0.0.zip`：这一版网页的完整静态文件；通过 HTTP/HTTPS 托管，不建议双击 `index.html` 使用蓝牙。
- `easyinput-beatbox-source-v1.0.0-backup1.zip`：恢复修正标签的源码、文档和发布镜像；包含发布依赖锁。也可下载 `v1.0.0-backup.1` 标签源码。
- `easyinput-beatbox-history-v1.0.0-backup1.bundle`：包含本版及恢复修正提交、两个固定标签及完整 Git 历史，可脱离 GitHub 恢复仓库。
- `SHA256SUMS.txt` 和 `RELEASE-ASSETS.sha256`：分别校验包内文件及上传资产。
- `manifest.json`：版本、硬件、地址、固件哈希、验证范围与未验证项的机器可读清单。
- `BACKUP1-ASSETS.sha256`：修正源码 ZIP / Git bundle 的校验；原 `RELEASE-ASSETS.sha256` 继续对应原九项附件中的八项数据文件，不被覆盖。

恢复源码：

```bash
git clone https://github.com/Xingchen-stars/easyinput-beatbox.git
cd easyinput-beatbox
git switch --detach v1.0.0-backup.1
```

脱离网络恢复：

```bash
git clone --branch codex/release-v1.0.0 easyinput-beatbox-history-v1.0.0-backup1.bundle easyinput-beatbox-restored
cd easyinput-beatbox-restored
git bundle verify ../easyinput-beatbox-history-v1.0.0-backup1.bundle
git switch --detach v1.0.0-backup.1
```

未来有新修改应创建新提交和新标签，不覆盖本版标签或替换同名发布资产。网页凭据、NVS 内容、Wi-Fi 密码、设备 MAC 和完整串口日志不进入公开备份；恢复到新的板子或网站后按 S7 重新登记。

## 已知限制

HMAC 是应用层访问控制，不是 Windows OS 配对，也不是 BLE 链路加密。新挑战防止直接重放旧认证答案；登记钥匙和普通鼓机消息仍以明文传输，本版不抵御无线窃听或登记窗口中的中间人。

USB 串口只能由一个程序独占。串口监视器、另一个 Edge/Chrome 标签和网页“USB 备用”不能同时打开同一个端口。USB 备用测试时停止串口监听；BLE 测试时可以保留 USB 供电及诊断采集。

`easyinput-factory/` 保存键盘模式集成源码与其原许可证，不代表本轮重新构建并验收了该整套键盘固件。默认更新包只更新 Beatbox；不会写入 factory、Bootloader、NVS 或声音资源。旧 `artifacts/release-v1.0.0/` 和历史诊断文档不是本版镜像的下载入口。
